Repeatable 10-Step Node Failure & Recovery Walkthrough Guide ▾
  1. Open Process Manager and submit 4 tasks under Round Robin.
  2. Switch to System Overview: Verify all 3 worker nodes are ONLINE (3 / 3) with active task loads.
  3. Switch to Fault Tolerance and select node-2.
  4. Click Simulate Node Failure (Stop Node).
  5. Notice that the Coordinator immediately marks node-2 as OFFLINE, and Online Nodes updates to 2 / 3.
  6. Observe the Recent Events timeline: Coordinator logs task migration from node-2 to node-1 or node-3.
  7. Return to Process Manager and submit a new task: confirm it is assigned only to surviving nodes (node-1 or node-3).
  8. Return to Fault Tolerance and click Restore / Reconnect Node (Heal) on node-2.
  9. Coordinator recognizes node-2 rejoining: status returns to ONLINE, and counter returns to 3 / 3.
  10. Verify in Lamport & Events that the entire failure, failover, and recovery sequence was logged with causal timestamps.
